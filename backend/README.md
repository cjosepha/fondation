```shell
# Launch unit tests (for fast tests execution, make sure that "localhost" and "hardhat" networks are commented in hardhat.config.ts)
npx hardhat test
REPORT_GAS=true npx hardhat test

# Launch tests with coverage
SOLIDITY_COVERAGE=true npx hardhat coverage

npx hardhat node

npx hardhat ignition deploy ./ignition/modules/Fondation.ts --network localhost

npx hardhat run ./scripts/impersonate.ts --network localhost

npx hardhat ignition deploy ./ignition/modules/Fondation.ts --network sepolia --verify

# Deploy FakeStrategyEURS on Sepolia testnet
npx hardhat ignition deploy ./ignition/modules/FakeStrategyEURS.ts --network sepolia --verify

```

## Description

The `Fondation` smart contract allows to stake wrapped Bitcoin `wBTC` and earn interests while keeping the advantages of being liquid.

When a user stakes some `wBTC` in `Fondation`, the contract mints the equivalent amount of `stBTC` to the user, according to the current exchange rate.

When a user unstakes some `stBTC` in `Fondation`, the contract burns those `stBTC` and sends to the user the equivalent amount of `wBTC` according to the current exchange rate.

The exchange rate is calculated by considering the total amount of wBTC the contract has in reserve, divided by the total supply of stBTC.

The Fondation contract takes a commission on the yields generated by a IFondationStrategy contract, owned by the Fondation contract owner.

The Fondation contract owner can accrue the yields generated by the IFondationStrategy contract, to increase the Fondation contract wBTC reserve and to receive the fees which are owed to him. To do so, he calls the `accrueYield()` function of Fondation.

The IFondationStrategy contract only accepts a specific asset as deposit, and generates yield in this asset.

In this implementation, the IFondationStrategy set is a FakeStrategy contract, which does nothing and can get yield only by calling the `addFakeYield()` function, providing the amount of strategy asset to add as yield.
